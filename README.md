# MSL documentation

Documentation for [MSL](https://github.com/onexay/msl), the Modern Subsystem for Linux: Linux distributions on macOS, the way WSL runs them on Windows.

The site uses Docusaurus and is published at **https://onexay.github.io/msl-docs/**. GitHub Actions builds pull requests and deploys the current site when a maintainer runs the publishing workflow.

## Preview the site

Install Node.js 22 or later, then run:

```console
$ npm ci
$ npm start
```

Open the local URL printed by Docusaurus. Run `npm run build` to create the static site in `build/`.

[CONTRIBUTING.md](CONTRIBUTING.md) covers the page layout and writing style. Report problems with MSL itself in [onexay/msl](https://github.com/onexay/msl/issues), and problems with these pages here.
